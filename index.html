    有沒有可以聽的鳥叫聲資料庫？

    有，而且是免費的。最推薦 xeno-canto（世界各地鳥友上傳的錄音，大多是 CC 創用授權，可以直接在網頁上播放），再來是 eBird／麥考利圖書館（康乃爾大學鳥類研究室，錄音最多、品質最好）。手機上可以裝 Merlin Bird ID，對著鳥叫聲錄音就能幫忙認是哪一種鳥。本網頁每一隻鳥都附了一段 xeno-canto 的真實錄音（標明錄音者與授權），揭曉答案後就能播放。

    xeno-canto 鳥聲資料庫

    全球最大的開放鳥聲資料庫，有超過百萬筆錄音，每一筆都標示錄音者、地點與 CC 授權。可以搜尋學名或英文名，篩選「Taiwan」只聽台灣錄的。非商業教學使用、標註來源即可。

    看台灣的錄音 ↗

    eBird ／ 麥考利圖書館

    康乃爾大學鳥類研究室的資料庫，每種鳥都有物種頁面，可聽叫聲、看照片與分布地圖。錄音品質好，但授權較嚴格，請直接在他們的網站上播放，不要下載轉貼。

    台灣鳥聲錄音 ↗

    Merlin Bird ID（手機 App）

    免費 App，打開「聲音辨識」對著窗外錄音，就會即時顯示可能是哪一種鳥。帶長輩到公園散步、帶小朋友戶外教學時很好用。

    Merlin 官網 ↗

    台灣生物多樣性網絡 TBN

    台灣的生物分布查詢平台，可以查某種鳥在台灣哪些地方被記錄過。它主要是「分布資料」，不是聲音資料庫，適合回答「這種鳥在我們附近有沒有？」。

    給帶領者的活動說明

    怎麼帶（30–45 分鐘）

    1. 用投影或大電視開啟本頁，選玩法：長輩建議「看照片猜」，小朋友可以玩「模糊照片」或「先聽叫聲」。
    2. 先不給提示，請大家說說看「牠是什麼顏色、多大、在哪裡看過」。
    3. 猜不到就按提示：體型 → 顏色 → 住哪裡 → 叫聲 → 有名的事 → 名字字數。卡住時可以按「給選項」。
    4. 揭曉後，挑 1–2 個小知識講，再用「跟長輩聊聊」的題目讓大家分享回憶。
    5. 最後一起聽叫聲、看一小段影片，請大家學學看牠怎麼叫。

    帶領小撇步

    1. 一次玩 6–8 隻就夠，留時間聊天比答對更重要。
    2. 長輩常用台語名或小名（厝鳥仔、白鷺鷥、加令），說出小名也算答對。
    3. 失智症長輩可改用「給選項」二選一或三選一，降低挫折感。
    4. 搭配動作：學鳥拍翅膀、學白鷺鷥單腳站，順便活動身體。
    5. 影片在 GitHub 網頁版可以直接播放；若網路不穩，先播本頁內建的叫聲錄音。
